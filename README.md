# PoetessEvangelina.github.io

The author's website of poetess Evangelina Sosedova.

## Android live wallpaper prototype

This repository also contains a native Android live-wallpaper prototype in [`android-live-wallpaper/`](android-live-wallpaper/). It is intended for a single-APK phone wallpaper app with an anime assistant that can show time, weather, battery status, and notification count.

Build instructions, Android permission notes, screen-scaling details, and low-battery fallback behavior are in [`android-live-wallpaper/README.md`](android-live-wallpaper/README.md).


### Download APK

Download page for the Android live-wallpaper APK: [`android-apk.html`](android-apk.html) / `https://PoetessEvangelina.github.io/android-apk.html`. The page now links to the release page and the build workflow first, because the direct APK URL returns 404 until GitHub Actions has built and published `zakoulok-waifu-wallpaper-debug.apk` in the `android-live-wallpaper-latest` release.
