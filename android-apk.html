🌸 Zakoulok Waifu Wallpaper

APK для Android-живых обоев с аниме-девушкой. Даже без разрешений на погоду и уведомления обои должны запускаться в ограниченном режиме: визуальная часть, время и батарея.

Почему раньше была ошибка 404: прямая ссылка на файл работает только после того, как GitHub Actions соберёт APK и создаст release android-live-wallpaper-latest. Если release ещё не создан, GitHub честно отдаёт 404 — самого APK-файла пока нет на сервере.
Открыть страницу APK-релиза Запустить/проверить сборку

После успешного workflow файл будет доступен по прямой ссылке:
https://github.com/PoetessEvangelina/PoetessEvangelina.github.io/releases/download/android-live-wallpaper-latest/zakoulok-waifu-wallpaper-debug.apk

  1. Откройте Запустить/проверить сборку и запустите workflow Build Android live-wallpaper APK.
  2. Дождитесь зелёной галочки сборки.
  3. Вернитесь на страницу APK-релиза и скачайте zakoulok-waifu-wallpaper-debug.apk.
  4. Если хотите собрать APK в App Builder, скачайте artifact zakoulok-waifu-wallpaper-app-builder-source.zip из workflow или загрузите папку android-live-wallpaper из репозитория; подробные шаги описаны в android-live-wallpaper/PUBLISH_APK.md.
